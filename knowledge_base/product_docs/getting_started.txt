Getting Started with CloudSupport Pro

Welcome to CloudSupport Pro! This guide will help you set up your account and start providing excellent customer support.

INITIAL SETUP

1. Account Creation
After signing up, you'll be guided through our setup wizard:
- Choose your company name and subdomain
- Select your time zone and language
- Set your business hours
- Choose your primary support channels

2. Customize Your Brand
Make CloudSupport Pro yours:
- Upload your company logo
- Set brand colors
- Customize email templates
- Configure your chat widget appearance
- Set up custom domains (Business/Enterprise plans)

3. Add Your Team
Invite agents to your account:
- Go to Settings > Team > Invite Agent
- Enter email addresses (bulk import available)
- Assign roles: Admin, Agent, or Viewer
- Create teams for department-based routing
- Set skills and expertise for smart routing

4. Configure Communication Channels

Email Support:
- Forward your support email to your CloudSupport Pro email address
- Or connect via IMAP/SMTP
- All emails automatically become tickets

Live Chat:
- Install the chat widget on your website
- Customize greeting messages
- Set up proactive chat triggers
- Configure offline messages

Social Media:
- Connect Facebook, Twitter, Instagram accounts
- All messages and mentions become tickets
- Respond directly from CloudSupport Pro

Phone Support (Business/Enterprise):
- Get a dedicated support phone number
- Or forward your existing number
- Set up IVR menus
- Configure call routing rules

5. Build Your Knowledge Base
Create self-service resources:
- Write help articles
- Create FAQs
- Add video tutorials
- Organize into categories
- Make public or private

6. Set Up Automation
Save time with smart automation:
- Auto-assign tickets based on keywords, channel, or priority
- Set up canned responses for common questions
- Create SLA rules for response and resolution times
- Configure escalation workflows
- Set up customer satisfaction surveys

UNDERSTANDING THE DASHBOARD

Your dashboard shows:
- Open tickets count
- Average response time
- Average resolution time
- Customer satisfaction score
- Agent performance metrics
- Channel distribution

You can customize dashboard widgets and date ranges.

HANDLING YOUR FIRST TICKET

1. When a ticket arrives, you'll get a notification
2. Click on the ticket to open it
3. Read the customer's issue
4. Check their history and previous conversations
5. Use AI-suggested responses or canned responses
6. Write your reply
7. Add internal notes if needed
8. Change ticket status (Open, Pending, Resolved)
9. Add tags for categorization
10. Click Send

KEYBOARD SHORTCUTS

Speed up your workflow:
- Cmd/Ctrl + K: Quick search
- Cmd/Ctrl + N: New ticket
- R: Reply to ticket
- Cmd/Ctrl + Enter: Send message
- N: Next ticket
- P: Previous ticket
- T: Add tag
- /: Focus search

MOBILE APP

Download our mobile app to help customers on the go:
- Receive push notifications for new tickets
- Respond to chats in real-time
- View customer information
- Add notes and tags
- Available for iOS and Android

BEST PRACTICES

1. Set clear expectations: Configure auto-responders to let customers know when to expect a response

2. Use templates: Create canned responses for common questions to save time

3. Personalize responses: Always use the customer's name and reference their specific situation

4. Be proactive: Use chat triggers to help customers before they ask

5. Tag consistently: Use tags to categorize tickets for better reporting

6. Follow up: Set reminders to check on resolved issues

7. Keep learning: Review your metrics weekly to identify improvement areas
